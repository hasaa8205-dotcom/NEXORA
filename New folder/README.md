# NEXORA AI

NEXORA AI нь семантик HTML, CSS болон ванилла JavaScript ашиглан бүтээсэн, олон хуудастай, төхөөрөмжид дасан зохицох хиймэл оюуныг суралцах, нээн илрүүлэх вэбсайт юм.

## Орон нутагт ажиллуулах

`index.html` файлыг орчин үеийн хөтөчөөр нээх эсвэл энэ хавтсыг статик вэб серверээр ажиллуулна уу. Build алхам, багц суулгах шаардлагагүй. Google Fonts боломжгүй байсан ч системийн sans-serif фонтоор ажиллана.

## Хуудсууд

- `index.html` — Нүүр хуудас болон онцлох хэсгүүд
- `explore.html` — Хайлт, шүүлтүүртэй ХО хэрэгслийн сан болон харьцуулалт
- `academy.html` — Анхан, дунд, ахисан түвшний хичээл болон ахицын бүртгэл
- `prompt-studio.html` — Заавар бүтээгч, хуулах үйлдэл, хайлттай жишээ зааврууд
- `showcase.html` — ХО ашиглах практик ажлын урсгалын ангилж үзэх галерей
- `favorites.html` — Хадгалсан ХО хэрэгслүүд
- `about.html` — NEXORA AI-ийн эрхэм зорилго, зарчмууд

## Төслийн бүтэц

- `css/style.css` — Одоо ашиглаж буй загварын систем болон дахин ашиглах боломжтой компонентууд
- `css/multipage.css` — Хуудасны нийтлэг бүтэц, дасан зохицох навигаци, шилжилт, хөдөлгөөн
- `js/navigation.js` — Нийтлэг навигаци, гар утасны цэс, идэвхтэй хуудасны төлөв, хуудас хоорондын шилжилт
- `js/main.js` — Хуудас тус бүрийн үйлдэл, шүүлтүүр, хадгалсан зүйлс, хичээлийн ахиц, заавар бүтээгч
- `js/tools.js` — ХО хэрэгслийн сангийн өгөгдөл
- `js/prompts.js` — Жишээ зааврын өгөгдөл

Хадгалсан хэрэгсэл болон дуусгасан хичээл энэ хөтөчийн `localStorage`-д хадгалагдана. Заавар бүтээгч төхөөрөмж дээрээ ажиллаж, агуулгыг ХО үйлчилгээнд илгээхгүй. Хэрэгслийн тайлбар, үнийн мэдээлэл нь танилцуулгын зориулалттай тул тухайн үйлчилгээ үзүүлэгчийн албан ёсны сайтаас шинэ мэдээллийг шалгана уу.

Хөдөлгөөнт дүрс нь `prefers-reduced-motion` тохиргоог хүндэтгэнэ. Хуудасны дотоод шилжилтийг ашиглахад хөтчийн буцах, урагшлах үйлдэл ажилласаар байна.
